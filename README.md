# Screen — versiuni

Acest repo conține **doar** installerele aplicației Screen și fișierul `version.json`.
Nu conține cod sursă.

- Descărcări: vezi [Releases](https://github.com/23botnari/screen-releases/releases).
- `version.json` este semnat digital (Ed25519). Aplicația acceptă doar fișiere cu semnătura validă,
  deci versiunea minimă și linkurile de descărcare nu pot fi modificate de altcineva.
